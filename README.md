# Слово в шляпе

Рабочий каркас мобильной командной игры на Flutter.

## Что уже реализовано

- создание от 2 до 6 команд;
- добавление игроков;
- настройка количества слов и времени хода;
- приватный ввод слов каждым участником;
- перемешивание карточек;
- три раунда: объяснение, пантомима и одно слово;
- таймер хода;
- действия «Угадано» и «Пропустить»;
- смена команд и объясняющих игроков;
- результаты каждого раунда;
- общий рейтинг и экран победителей.

## Архитектура

Проект разделён на UI, контроллер игровой логики, модели и репозиторий. Это облегчает добавление онлайн-комнат, локального сохранения, тематических наборов и платных функций.

```text
lib/
├── app/                         # приложение и тема
├── core/                        # общие константы и утилиты
└── features/game/
    ├── data/                    # хранение партии
    ├── domain/                  # модели и типы раундов
    └── presentation/
        ├── controllers/         # игровая логика
        ├── screens/             # экраны
        └── widgets/             # повторно используемые элементы
```

## Запуск на Windows

1. Установить Flutter SDK и Android Studio.
2. Распаковать проект.
3. Открыть PowerShell в папке проекта.
4. Выполнить:

```powershell
flutter create --platforms=android,ios .
flutter pub get
flutter run
```

Папки `android` и `ios` будут созданы Flutter автоматически.

## Сервер онлайн-комнат

Версия 2.5.2 использует защищённый WebSocket и постоянное состояние комнаты в Cloudflare Durable Object. Команды, слова, счёт, текущий раунд и таймер сохраняются на сервере до 6 часов. После перезапуска VK, Telegram или браузера игрок автоматически возвращается в свою комнату и продолжает с актуального экрана; приглашения копируются через системный API VK или буфер обмена браузера с проверкой результата.

```powershell
npm.cmd install
npm.cmd run dev:worker
npm.cmd run test:realtime
npm.cmd run deploy:worker
```

Адрес опубликованного Worker задаётся константой `MULTIPLAYER_SERVER_URL` в `app.js`. Для локальной разработки автоматически используется `ws://127.0.0.1:8787`.
